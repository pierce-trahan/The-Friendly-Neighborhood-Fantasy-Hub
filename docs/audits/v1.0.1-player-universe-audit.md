# V1.0.1 Bundled Player-Universe Audit

Date: 2026-08-03

Branch: `agent/v1-bundled-player-universe`

Release candidate: `1.0.1`

## Release Decision

Pass. A fresh offline V1.0.1 launch automatically populated the local SQLite
database with the bundled nflverse player snapshot. No manual sample load or
network request was required, the same database survived a restart without
duplicate rows, and the Player Universe was usable in the production frontend.

Five focused backend tests passed:

## Offline and Visual QA

A production backend and built frontend were launched on `127.0.0.1:8765`
with a new temporary data directory and no data-source network call. The health
API returned V1.0.1 and the player API returned 1,148 rows. The server was
restarted against the same directory; the total remained 1,148.

At 1440 by 900, the Player Universe showed:

- the source and CC BY 4.0 notice without clipping;
- `1148 players` before filtering;
- QB-first canonical ordering;
- no sample-load control;
- a successful `Josh Allen` search with BUF, QB, active, and 2018; and
- no browser warnings or errors.

The temporary upstream CSV and QA database were removed after verification.
Only the transformed attributed JSON artifact remains in the repository.

## Remaining Boundary

V1.0.1 intentionally ships a curated fantasy draft pool rather than the full
25,039-row historical nflverse database. Runtime launch does not refresh from
the network. Future refreshes use the reproducible build script and a normal,
reviewed release so source drift cannot surprise a user on draft night.
