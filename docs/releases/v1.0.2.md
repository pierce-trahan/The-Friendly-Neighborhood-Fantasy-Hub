# V1.0.2 — Market-Led Mock Draft Correction

**Release date:** 2026-08-03

V1.0.2 corrects the Mock Lab behavior exposed by the V1.0.1 full player
database. CPU teams no longer treat alphabetical order as their value board
when the user's Personal Board contains only a few ranked players.

## What changed

- bundled a reviewed 621-player dynasty 2QB expert-consensus snapshot for
  offline Superflex practice;
- froze a market rank on matched candidates when each new mock is created;
- added the versioned `market-board-v1` CPU engine while retaining the legacy
  practice-board engine for unavailable-data fallback and old mocks;
- kept the Personal Board separate and authoritative for the user's rankings,
  notes, and decisions;
- displayed the market source, source date, match coverage, and limitations in
  the Mock Lab;
- carried `MARKET_ECR_BASELINE` and evidence limitations into every saved CPU
  decision audit; and
- added a reproducible source transformation script and an end-to-end
  one-player-board regression test.

## Evidence limits

The initial baseline is FantasyPros expert consensus data distributed through
the DynastyProcess open-data repository. It is ECR, not ADP. Dynasty 2QB is
used as a Superflex proxy, tight-end premium is not explicitly represented,
and V1.0.2 does not yet model an ADP distribution or a player's probability of
returning at a later pick.

The baseline is a simulation input, not an objective grade. CPU profiles,
roster needs, and seeded variation can move nearby players. Every user pick
still requires explicit confirmation.

## Existing mocks

Existing `practice-board-v1` mocks remain readable and auditable. Start a new
mock to use the market-led engine and the frozen July 31 snapshot.

Full verification evidence is recorded in the
