# Friendly Neighborhood Fantasy Hub V1.0.0

V1 is the first tryable Draft Lab release: a private, local-first draft-night
companion that organizes the user's own convictions without drafting for them.

## What You Can Try

- import and normalize a relevant player pool;
- build, tier, annotate, and export Personal Boards;
- run bounded pairwise Gut ELO sessions without surrendering board authority;
- create recoverable live draft rooms with snake, linear, or third-round-
  reversal order;
- practice deterministic, seeded CPU mocks and strategy pivots;
- use explainable value, return-risk, and pick-only trade-up alerts from approved
  local evidence;
- preserve Blind view without leaking Personal Board context;
- correct and undo picks with revision guards;
- complete 10-team, 24-round Entropy-shaped drafts fully offline;
- generate, compare, and export saved post-draft reports; and
- relaunch after interruption with saved work restored.

## Draft-Night Safety

- The one-click Windows launcher binds only to `127.0.0.1`.
- Accepted board and draft changes save to the local SQLite database.
- Each routine launch creates and verifies a private SQLite backup by default.
- Personal Board and draft-state CSV exports provide portable fallbacks.
- Core draft-night work has no required cloud service after setup.
- Source timestamps and unavailable evidence states remain visible instead of
  being guessed.

Start with [the V1 Draft-Night Guide](../guides/v1-draft-night.md), then
double-click `Launch Friendly Hub.cmd`.

## Deliberate V1 Limits

V1 does not include automated drafting, projections, waivers, season
management, a player-plus-pick trade calculator, required cloud infrastructure,
or a packaged desktop executable. These remain explicit future roadmap work.
