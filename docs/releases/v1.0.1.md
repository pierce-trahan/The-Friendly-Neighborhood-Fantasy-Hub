# Friendly Neighborhood Fantasy Hub V1.0.1

V1.0.1 corrects the first-launch player experience. The Hub now opens with a
real, current, local player database instead of asking the user to load a
fictional sample or create players.

## What Changed

- bundled 1,148 current fantasy-relevant QB, RB/FB, WR, TE, and K records;
- included 239 players whose nflverse rookie season is 2026;
- seeded the snapshot into SQLite automatically before the API becomes ready;
- kept launch fully offline with no runtime call to nflverse;
- preserved exact-ID player corrections and every Personal Board field;
- skipped uncertain name-only collisions instead of silently merging them;
- retained optional CSV import and canonical CSV export for power users; and
- added visible source, timestamp, transformation, and CC BY 4.0 attribution.

The transformed snapshot comes from the nflverse `players.csv` release updated
August 2, 2026. See the
[bundled player-universe specification](../specs/v1-bundled-player-universe.md)
for the complete pool, provenance, refresh, and non-overwrite contract.

## First Launch

Double-click `Launch Friendly Hub.cmd`, open **Players**, and begin searching or
filtering. The player database is already there. You do not need to click an
import button, download a dataset, or be online.

## Deliberate Limit

The snapshot is curated for V1 fantasy draft work; it is not the full nflverse
historical database. Maintainer-reviewed snapshots are shipped with releases
so draft-night launch never depends on an upstream service.

## Verification

See the [V1.0.1 player-universe audit](../audits/v1.0.1-player-universe-audit.md)
for integrity, idempotency, offline launch, regression, and visual evidence.
